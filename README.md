

The plan of this project is to build a complete flight computer with the ability to collect, process, and store data throughout the entire flight of a model rocket.

The flight computer will be built around a WROOM ESP32 and integrate multiple sensors and subsystems to measure the rocket's behavior throughout the entire flight. The planned system includes an IMU for acceleration and orientation, a barometric pressure sensor for altitude estimation, GPS for position tracking, onboard data logging via a microSD card, a camera to record the flight, and telemetry.

Rather than building a simple model rocket, the objective is to build an intelligent rocket that is able to gather and process data in real time. To achieve this, the project includes designing a custom PCB for the flight computer, finding and experimenting with suitable electronic components, developing the firmware and software, and, first of all, designing a functional rocket especially selecting the right materials and motors.

My goal is to create a complete engineering project from the ground up while building my first model rocket and learning about the different engineering challenges involved along the way.

Project Goals: 

1. Design and build a functional model rocket.
2. Experiment with different motors and materials.
3. Design a custom PCB and select the right components for the project.
4. Test the completed PCB on the ground to ensure reliable operation under normal conditions.
5. Perform a complete flight test by launching the fully integrated rocket.
6. Analyze the gathered flight data and determine whether the collected data is accurate and useful.
